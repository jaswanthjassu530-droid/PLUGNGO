# Jaswanth Dunaboina - Portfolio

Personal portfolio of a first-year B.Tech CSE student at Aditya University, aspiring to become a cybersecurity engineer.

## Open locally
Double-click index.html. Keep style.css and script.js alongside it.

## Edit
- index.html: biography, education, learning and interests
- style.css: purple theme, responsive layouts and animations
- script.js: cursor effects, hover interactions and scroll reveals

Static HTML, CSS and JavaScript. No installation or build step required.
